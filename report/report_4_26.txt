         CoPE-Delta-Det: Compressed-Domain Object Detection for HEVC
                        Progress Report - April 26, 2026
================================================================================

This report presents the definitive full-validation results using the best
checkpoint (epoch 28, loss 18.7988) with the --freeze_classes evaluation
protocol. It supersedes all prior partial or incorrectly-run evaluations.


1. EVALUATION PROTOCOL FIXES
--------------------------------------------------------------------------------

1.1 --freeze_classes flag (new)

  evaluate.py previously propagated the fusion head's class logits to P-frames
  (current_classes = [cls_scores]). For early and resumed checkpoints whose
  class branch is not fully trained, this produced near-random class predictions
  and collapsed CoPE mAP to ~3% despite correct box tracking.

  New flag --freeze_classes: P-frames inherit the I-frame YOLO class IDs
  unchanged. This is semantically correct for video detection (object class
  does not change between frames) and makes cross-checkpoint comparisons fair.

  Impact: epoch-28 CoPE mAP@0.5 went from 3.07% (without) to 24.88% (with).

1.2 evaluate_baselines.py max_eval default

  Default changed from 50 to None (all GOPs). The 50-GOP default was causing
  highly variable and unrepresentative numbers (7.92% YOLO Full on 50 GOPs vs
  34.76% on the full 10,753-GOP val split).

1.3 run_overnight_eval.py crash fix

  load_json() was returning data[0] for all lists, including the multi-element
  loss history. Fixed to only unwrap single-element lists (baseline output
  format). Loss history is now read via a separate load_loss_history() function.
  --freeze_classes added to all CoPE eval subprocess calls.

3. DEFINITIVE FULL-VALIDATION RESULTS (10,753 GOPs)
--------------------------------------------------------------------------------

  Setup:
    Dataset:    ImageNet VID val, ALL 10,753 GOPs
    YOLO:       runs/detect/yolov8m_vid/weights/best.pt (VID-finetuned, nc=30)
    Class map:  identity
    CoPE ckpt: checkpoints/vid_finetuned_best.pt (epoch 28, loss 18.80)
    Policy:     disabled (thresh=999) — pure delta encoder, 6.2% decode
    Eval mode:  --freeze_classes for CoPE rows

  +---------------------------+---------+-----------+---------+-----------+
  | Method                    | mAP@0.5 | mAP@.5:95 |  Decode |   ms/GOP  |
  +---------------------------+---------+-----------+---------+-----------+
  | YOLO Full                 |  34.76% |    22.91% |  100.0% |   230 ms  |
  | Copy-Paste                |  26.17% |    12.99% |    6.2% |    18 ms  |
  | CoPE-Det (block-match)    |  24.88% |    12.21% |    6.2% |   100 ms  |
  | CoPE-Det (PyAV MVs)       |  24.06% |    11.97% |    6.2% |   102 ms  |
  +---------------------------+---------+-----------+---------+-----------+

  Key observations:

  [1] YOLO Full ceiling: 34.76% mAP@0.5 at 230 ms/GOP (decodes every frame).

  [2] CoPE-Det vs YOLO Full: 24.88% / 34.76% = 71.6% of accuracy at 6.2%
      of the decode cost (100 ms vs 230 ms/GOP). The 100 ms/GOP includes
      YOLO on the I-frame + delta encoder on 15 P-frames.

  [3] CoPE-Det vs Copy-Paste: CoPE (24.88%) is 1.29pp below Copy-Paste
      (26.17%) on the full 10,753-GOP val split. The delta encoder has not
      yet surpassed the trivial freeze-box baseline on the full dataset.
      On the 500-GOP ablation subset CoPE reaches 28.51% (above Copy-Paste),
      indicating the gap is sensitive to which GOPs are sampled.

  [4] PyAV zero-shot transfer gap: 0.82pp (24.06% vs 24.88%). A model
      trained exclusively on block-matched MVs transfers to real codec MVs
      with less than 1pp penalty on the full 10,753-GOP evaluation.

  [5] Latency: Copy-Paste is fastest (18 ms/GOP, 6.2% decode) because it
      skips the delta encoder entirely. CoPE adds ~82 ms for the delta
      encoder pass over 15 P-frames (~5.5 ms/P-frame). This is the cost
      of the tracking computation.


4. ABLATION STUDY (500 GOPs, epoch-28, --freeze_classes)
--------------------------------------------------------------------------------

  +----------------------+---------+-----------+---------------------------+
  | Ablation mode        | mAP@0.5 | mAP@.5:95 | vs full model             |
  +----------------------+---------+-----------+---------------------------+
  | Full (MV + Appear.)  |  28.51% |    15.11% | reference                 |
  | MV only (Appear.=0)  |  25.79% |    13.57% | -2.72pp (MVs alone weaker)|
  | Appearance only(MV=0)|  24.57% |    12.55% | -3.94pp (Appr. alone weak)|
  +----------------------+---------+-----------+---------------------------+

  Key findings:

  [1] Both features contribute: removing either MV or appearance degrades
      mAP meaningfully. The full model outperforms either component alone.

  [2] Appearance slightly more important: appearance-only loses 3.94pp
      vs MV-only losing 2.72pp. MVs alone retain more accuracy. This is
      consistent with the hypothesis that MVs directly encode object
      displacement while appearance features (residual energy, partition
      depth, prediction mode) provide supporting context.

  [3] Appearance features improved significantly vs April 19 ablation:
      appearance-only went from 19.99% (epoch 24, old eval) to 24.57%
      (epoch 28, freeze_classes). The epoch-28 checkpoint learned better
      use of appearance features than epoch 24.

  Comparison with April 19 ablation (epoch-24, 500 GOPs, no freeze_classes):
    Full:            26.43% → 28.51%  (+2.08pp, epoch 28 better)
    MV only:         24.95% → 25.79%  (+0.84pp)
    Appearance only: 19.99% → 24.57%  (+4.58pp, large gain)


5. KNOWN LIMITATIONS
--------------------------------------------------------------------------------

  [A] CoPE below Copy-Paste on full val: 24.88% vs 26.17%. The delta
      encoder is trained to minimise box regression loss on training GOPs
      but the validation set contains harder sequences where propagating
      I-frame boxes is better than updating them.

  [B] Class branch untrained: the fusion head's class logits are unreliable
      (requires --freeze_classes). Stage 3 training (SaliencyRefreshPolicy +
      class branch) has not been run. Until then, class predictions should
      always inherit from the YOLO I-frame anchor.

  [C] Optimizer state not saved on resume: every resume run rebuilds Adam
      with cold momentum buffers. This caused the epoch-20 and epoch-29
      spikes. Future resumes should use --lr 5e-5 to mitigate.

  [D] Two checkpoint lineages: vid_finetuned_* (original run) and
      finetuned_* (resumed run without --prefix). Now merged: epoch-28
      weights from finetuned_model_epoch_28.pt are the new canonical
      vid_finetuned_best.pt.


6. WHAT IS NEXT
--------------------------------------------------------------------------------

  Priority 1 — Close the CoPE vs Copy-Paste gap

    The 1.29pp deficit suggests the delta encoder is making slightly wrong
    updates on some sequences. Options:
      a) Train more epochs with --lr 5e-5 and --prefix vid_ for clean naming
      b) Add a residual skip: if delta encoder confidence is low, fall back
         to copy-paste rather than applying a potentially bad update
      c) Train Stage 3 (SaliencyRefreshPolicy) so the model knows when NOT
         to update boxes

  Priority 2 — Train Stage 3: SaliencyRefreshPolicy

    The policy has learnable weights (w1, w2, threshold) that have never
    been trained. A trained policy would:
      - Trigger YOLO refreshes on high-motion / high-residual frames
      - Skip delta updates when confidence is low
      - Potentially raise mAP while keeping average decode below 15%

    Command (once Stage 2 is stable):
      python training/train_policy.py  [to be implemented]

  Priority 3 — Re-train with optimizer state saved

    Add optimizer state dict to the checkpoint save/load cycle in finetune.py
    to eliminate the cold-momentum spike on every resume. Then run a clean
    30-epoch training from scratch with --lr 1e-4 --prefix v2_.

  Priority 4 — Full report / paper writeup

    With definitive numbers now available, the results section of the paper
    can be written. The key claim: CoPE-Det achieves 71.6% of YOLO Full
    accuracy at 6.2% of decode cost on 10,753 ImageNet VID val GOPs.
