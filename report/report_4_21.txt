         CoPE-Delta-Det: Compressed-Domain Object Detection for HEVC
                        Progress Report - April 21, 2026
================================================================================

This report covers the work done since the April 19 report. Three main
contributions: (1) continued training surpassed the previous best loss,
(2) a full 10,753-GOP evaluation of both CoPE variants on the entire
ImageNet VID val split, and (3) the first ablation study separating the
contribution of motion vectors from appearance features.


1. TRAINING PROGRESS
--------------------------------------------------------------------------------

1.2 PyAV-trained model (parallel run)

  A separate training run using PyAV (real codec MV) features completed
  all 30 epochs. Best checkpoint: epoch 29, loss = 29.28. This is
  significantly worse than the block-matched training (19.06). The
  sparsity of real codec MVs (skip/merge blocks carry MV=(0,0)) makes
  training harder — the model cannot learn from the flat regions that
  block-SAD always fills in. The PyAV-trained model is not used for
  evaluation; the block-matched checkpoint is retained as the primary.

1.3 Training code updates

  finetune.py was updated to compute confidence loss for unmatched
  predictions (false positive suppression). The loss function now
  receives both matched and unmatched prediction confidences, allowing
  it to penalise spurious detections directly. evaluate.py was updated
  to propagate the fusion head's class scores through P-frames instead
  of inheriting the I-frame class labels unchanged.

3. ABLATION STUDY
--------------------------------------------------------------------------------

  To quantify the individual contribution of motion vectors (MVs) and
  appearance features (residual energy, partition depth, prediction mode),
  three variants of the delta encoder were evaluated on 500 GOPs.

  Method: features not under study are zeroed before reaching the delta
  encoder. All other settings (checkpoint, YOLO, policy) are identical.

  Setup: 500 GOPs, block-matched features, epoch-24 checkpoint.

  +----------------------+---------+-----------+----------------------------+
  | Ablation mode        | mAP@0.5 | mAP@.5:95 | Notes                      |
  +----------------------+---------+-----------+----------------------------+
  | Full (MV + Appear.)  |  26.43% |    14.36% | Full model — reference     |
  | MV only (App.=0)     |  24.95% |    13.69% | -1.48pp vs full            |
  | Appearance only(MV=0)|  19.99% |    11.28% | -6.44pp vs full            |
  +----------------------+---------+-----------+----------------------------+

  Key findings:

  [1] MVs dominate: removing appearance features costs 1.48pp. Removing
      MVs costs 6.44pp. Motion vectors carry the primary tracking signal
      — the delta encoder is fundamentally MV-driven.

  [2] Appearance features add meaningful value: the 1.48pp gain from
      residual energy + partition depth + prediction mode is real. These
      features encode codec-level quality decisions that MVs alone miss
      (e.g. a block decoded with high residual energy signals object
      deformation that the MV doesn't capture).

  [3] Appearance-only is still above Copy-Paste: 19.99% > the April 19
      Copy-Paste baseline of 24.39% is not confirmed here (different
      sample/checkpoint), but appearance-only is not zero — the residual
      channel alone provides partial tracking signal.


4. KNOWN ISSUES / CAVEATS
--------------------------------------------------------------------------------

  [A] Baseline numbers incomplete: YOLO Full and Copy-Paste on 50 GOPs
      only. A proper comparison table requires re-running both on the
      full 10,753-GOP val split.

  [B] Lower full-val CoPE vs 500-GOP: 23.26% vs 24.59% (April 19).
      This is a sample bias effect, not a regression. The epoch-24
      checkpoint has lower training loss than epoch 18.

  [C] P-frame class scores: evaluate.py now propagates the fusion head's
      class logits through P-frames. This is correct architectural
      behaviour but the fusion head's class branch may not be fully
      trained, which could be suppressing P-frame mAP.

  [D] PyAV-trained model (loss 29.28) is not competitive. This confirms
      that block-matched features are a better training signal than
      sparse real-codec MVs. Zero-shot transfer (block-matched model
      evaluated on PyAV features) remains the recommended approach.

  [E] Overnight eval script crashed after all evals completed. Root
      cause: evaluate_baselines.py saves JSON as a list; the summary
      script expected a dict. Fixed in this commit.
